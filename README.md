# tripmate — Панель путешественника

Учебный проект по практическому заданию №2 «Интерактивная панель управления UI-компонентами».

## Возможности

- Три типа виджетов: список дел, погода и курсы валют.
- Добавление виджетов кнопками на панели.
- Сворачивание и удаление карточек.
- Запрет одновременного добавления двух виджетов одного типа.
- Список дел: добавление, отметка выполнения и удаление задач.
- Погода во Франкфурте-на-Майне через Open-Meteo.
- Курс EUR → USD через Frankfurter.
- Состояния загрузки, ошибки и кнопка повторного запроса у сетевых карточек.
- Сохранение состава панели, состояния сворачивания и задач в `localStorage`.
- После перезагрузки погода и валюты загружаются заново.
- Адаптивная сетка для компьютера, планшета и телефона.

## Как запустить

1. Распакуйте архив проекта.
2. Откройте папку `traveler_dashboard` в Visual Studio Code.
3. Запустите `index.html` через расширение **Live Server** (рекомендуется), либо используйте любой локальный сервер, который поддерживает ES-модули.
4. Не открывайте файл двойным щелчком через `file://`: браузер может блокировать загрузку ES-модулей и запросы API.

Сборка, npm и дополнительные библиотеки не требуются.

## Использованные API

1. **Open-Meteo** — текущая погода для Франкфурта-на-Майне.  
   Документация: https://open-meteo.com/en/docs  
   Запрос: `https://api.open-meteo.com/v1/forecast` с координатами города и параметрами текущей погоды.

2. **Frankfurter** — курс EUR к USD.  
   Документация: https://frankfurter.dev/  
   Запрос: `https://api.frankfurter.dev/v1/latest?base=EUR&symbols=USD`

Оба источника используются без секретного API-ключа. Если API недоступен, карточка показывает сообщение об ошибке и кнопку «Повторить», а остальные виджеты продолжают работать.

## Где используются классы и модули

- `UIComponent.js` — базовый класс карточки, общие кнопки, сворачивание и удаление.
- `ToDoWidget.js` — класс списка дел, наследуется от `UIComponent`.
- `WeatherWidget.js` — класс погоды, наследуется от `UIComponent`.
- `CurrencyWidget.js` — класс валют, наследуется от `UIComponent`.
- `Dashboard.js` — управление экземплярами виджетов, восстановление и сохранение.
- `main.js` — точка входа, подключение кнопок к панели.

Каждый JS-файл использует ES-модули `import` и `export`.

## Проверка по заданию

1. Добавьте все три виджета.
2. Попробуйте добавить второй виджет того же типа — появится подсказка.
3. Сверните и разверните каждую карточку.
4. Добавьте несколько задач, отметьте часть выполненными, удалите одну.
5. Обновите страницу — состав панели и задачи должны восстановиться.
6. Удалите виджет и добавьте его снова пять раз — действия должны срабатывать по одному разу.
7. Проверьте погоду и валюту при включённом интернете.
8. Отключите интернет и нажмите «Повторить» — появится сообщение об ошибке, остальные карточки останутся рабочими.
9. Измените ширину окна до мобильного размера — карточки должны перестроиться в одну колонку.

## Использование нейросети

При подготовке проекта использовалась нейросеть ChatGPT для пошаговой разработки структуры, классов, виджетов, API-запросов, сохранения и адаптивного оформления.

Примеры полезных промптов:
- «Создай базовый класс UIComponent для карточек виджетов с кнопками сворачивания и удаления».
- «Создай класс виджета, который получает данные через fetch, показывает загрузку и ошибку с кнопкой повтора».
- «Добавь сохранение состояния панели и задач в localStorage, обработай повреждённый JSON и недоступность хранилища».

## Важно

Актуальные значения погоды и валют зависят от доступности внешних API и интернет-соединения. Данные не подменяются демонстрационными значениями.
